# 趣味刷题小站第一版需求分档

## 一、项目定位

“趣味刷题小站”第一版定位为单端网页应用，不区分教师端和学生端。任何用户都可以创建课程、上传资料、生成题库，也可以加入已有课程进行章节练习。

项目核心不是单纯做一个 AI 聊天老师，而是把 AI 嵌入到刷题流程中：学生在具体题目中选错、选择“模糊”或提交简答后，AI 基于当前题目、学生答案、标准答案和知识点主动发起引导，并允许学生继续围绕该题对话。

核心特点：

- 主资料优先：主资料决定“考什么”和“怎么考”。
- 补充资料辅助：补充资料用于识别章节、理解课程背景、辅助判断知识难度。
- 题库预生成：每章按难度层生成结构化题库。
- 即时 AI 引导：AI 不脱离题目空聊，而是在错题、模糊、简答提交后介入。
- 本地存储：第一版使用 localStorage 保存课程、章节、题库和本次刷题状态。

## 二、第一版必须实现

### 1. 首页入口

首页保留《第一版页面.html》的新粗野主义风格，包含两个主要按钮：

- 创建课程
- 加入课程

第一版不做登录、注册、用户身份、教师端、学生端、班级管理和权限系统。

### 2. 创建课程

点击“创建课程”后，弹出或进入课程名称输入页。

规则：

- 用户输入课程名称。
- 系统检查 localStorage 中是否已有同名课程。
- 如果课程已存在，提示“该课程已存在，请直接加入课程或更换课程名称”。
- 如果课程不存在，进入资料上传页。

### 3. 资料上传

创建课程后进入资料上传页，包含两个上传入口。

主资料：

- 试卷
- 作业
- 课堂例题
- 章节练习
- 老师重点题

主资料作用：

- 决定考查范围。
- 决定题型风格。
- 决定常考点。
- 决定题目难度。
- 决定答案标准。

补充资料：

- PPT
- 教材
- 教案
- 课程大纲

补充资料作用：

- 识别章节结构。
- 帮助 AI 理解学生正在学什么。
- 辅助判断知识背景和学习难度。
- 辅助生成解析。

资料优先级规则：

- 主资料优先级最高。
- 补充资料只能作为辅助。
- 主资料与补充资料冲突时，以主资料为准。
- 不允许生成两类资料均无依据的题目。

### 4. DeepSeek API 预留与真实调用

第一版使用 DeepSeek API。

代码中需要保留清晰的 API 替换位置，包括：

- API Key
- API URL
- 模型名称
- 请求函数

建议封装为统一函数：

```js
async function callDeepSeek(messages, options = {}) {
  // TODO: 在此处替换 DeepSeek API Key、接口地址和模型名称
}
```

第一版需要真实调用 DeepSeek，但要保留后续替换其他模型 API 的空间。

### 5. 章节生成

课程创建后，章节主要根据补充资料生成。

规则：

- 补充资料用于识别章节目录和知识结构。
- 主资料用于匹配每章重点、常考点和题目风格。
- 如果主资料无法明确归属章节，由 AI 根据知识点自动归类到对应章节。

### 6. 每章题库结构

第一版取消“错题补练题”。

第一版取消填空题。

每章生成 4 个难度层，每层 10 题，共 40 题。

| 难度层 | 单选 | 判断 | 简答 | 合计 |
|---|---:|---:|---:|---:|
| 0-39 | 6 | 3 | 1 | 10 |
| 40-59 | 6 | 3 | 1 | 10 |
| 60-79 | 6 | 3 | 1 | 10 |
| 80-100 | 6 | 3 | 1 | 10 |

每道题必须包含：

- question_id
- course_name
- chapter
- knowledge_point
- question_type
- difficulty_band
- difficulty_score
- ability_dimension
- stem
- options
- answer
- explanation
- scoring_rubric
- source_basis
- source_priority

题型说明：

- 单选题：A/B/C 为题目选项，D 永远为“模糊”。
- 判断题：正确 / 错误 / 模糊。
- 简答题：学生输入文字后点击提交，由 DeepSeek 判分。

### 7. 题目生成与难度复核

采用“生成 + Rubric 复核 + 不合格重写”的流程。

流程：

1. AI 根据主资料和补充资料生成题目。
2. AI 按 Rubric 对每道题做难度复核。
3. 如果题目难度分数不在目标区间，要求 AI 保持知识点和题型不变，重写题目。
4. 合格题目保存到 localStorage。

难度分数采用百分制，不同难度层不重合：

- 0-39：基础题
- 40-59：巩固题
- 60-79：提高题
- 80-100：挑战题

难度复核 Rubric 建议包含：

- 知识记忆负担
- 推理步骤数量
- 易混淆程度
- 应用复杂度
- 表达要求

### 8. 前置知识诊断

学生选择第 N 章练习时，系统优先从第 N-1 章题库中抽取 10 道单选题作为前置知识诊断。

规则：

- 每题 10 分，满分 100 分。
- 诊断题只使用单选题。
- 诊断题来自题库生成完成后的已有题库。

抽题比例：

| 难度层 | 单选数量 |
|---|---:|
| 0-39 | 3 |
| 40-59 | 3 |
| 60-79 | 3 |
| 80-100 | 1 |

特殊情况：

- 如果学生练习第一章，没有前一章，则从第一章题库中抽取诊断题。
- 如果上一章单选题不足，则从当前章节同难度层单选题补齐。

### 9. 正式刷题阶段

正式刷题每轮固定 10 题，满分 100 分。

题型与分值：

| 题型 | 数量 | 每题分值 | 合计 |
|---|---:|---:|---:|
| 单选 | 6 | 10 | 60 |
| 判断 | 3 | 5 | 15 |
| 简答 | 1 | 25 | 25 |
| 合计 | 10 | - | 100 |

抽题规则：

- 根据前置诊断分数选择对应难度层。
- 0-39 分：抽 0-39 难度层。
- 40-59 分：抽 40-59 难度层。
- 60-79 分：抽 60-79 难度层。
- 80-100 分：抽 80-100 难度层。

所有学生正式刷题题量一致，只改变题目难度层，不改变题型数量。

### 10. 判分规则

单选题：

- 使用题库标准答案判分。
- A/B/C 中选中正确答案得 10 分。
- 选错得 0 分。
- 选择 D“模糊”得 0 分，并触发 AI 引导。

判断题：

- 使用题库标准答案判分。
- 判断正确得 5 分。
- 判断错误得 0 分。
- 选择“模糊”得 0 分，并触发 AI 引导。

简答题：

- 使用 DeepSeek 按评分点判分。
- 满分 25 分。
- 题库中每道简答题必须包含评分点。
- AI 只能根据给定评分点评分，不能自行扩展评分标准。

简答题评分输出建议：

```json
{
  "score": 0,
  "hit_points": [],
  "missing_points": [],
  "feedback": "",
  "guiding_question": ""
}
```

说明：

- AI 简答评分用于即时学习反馈。
- 后续正式教学评价仍可由教师最终判断。

### 11. AI 即时引导

第一版的核心创新点是“题目嵌入式 AI 对话引导”。

AI 不作为独立聊天机器人出现，而是嵌入每道题的作答过程。

触发条件：

- 单选题选错。
- 单选题选择 D“模糊”。
- 判断题选错。
- 判断题选择“模糊”。
- 简答题点击提交并完成 AI 判分。

触发后：

- AI 先说话。
- 学生可以继续对话。
- 对话围绕当前题目展开。

AI 引导上下文必须包含：

- 课程名称
- 章节名称
- 当前题目
- 题型
- 知识点
- 难度层
- 学生答案
- 正确答案
- 标准解析
- 简答评分点
- 当前题目的历史对话

AI 引导要求：

- 不直接变成开放闲聊。
- 不脱离当前题目。
- 不引入资料外知识。
- 优先使用追问、提示、类比方式引导学生思考。
- 可以指出错因，但避免只给最终答案。

建议命名：

- 题目嵌入式 AI 对话引导
- 错题/模糊触发的即时对话式学习支架

### 12. 本轮学习报告

做完 10 题后，DeepSeek 汇总薄弱点和建议。

报告内容：

- 本轮得分
- 错题数量
- 模糊题数量
- 简答题得分
- 薄弱知识点
- 能力表现总结
- 下一轮学习建议

第一版只保存本次刷题状态和报告，不做班级统计，不做教师后台。

## 五、第一版技术选型

建议保持最小实现。

- 前端：HTML + CSS + JavaScript
- 样式：完全沿用《第一版页面.html》的新粗野主义风格
- 存储：localStorage
- AI：DeepSeek API
- 页面形态：单页面应用

localStorage 行为：

- 刷新页面后课程和题库不会丢失。
- 同一浏览器中可以继续加入已有课程。
- 清除浏览器缓存、换浏览器、换电脑后数据会丢失。
- 第一版只保存结构化结果，不长期保存原始上传文件。

## 六、核心流程总览

```text
首页
├── 创建课程
│   ├── 输入课程名称
│   ├── 检查是否重复
│   ├── 上传主资料
│   ├── 上传补充资料
│   ├── DeepSeek 生成章节
│   ├── DeepSeek 生成每章题库
│   ├── Rubric 复核难度
│   └── 保存到 localStorage
│
└── 加入课程
    ├── 选择已有课程
    ├── 选择章节
    ├── 前置知识诊断
    ├── 根据诊断分数选择难度层
    ├── 正式刷题 10 题
    ├── 错题/模糊/简答触发 AI 对话引导
    └── 生成本轮学习报告
```

## 七、可用于申报书的表述

本项目第一版采用单端网页应用模式，不区分教师端和学生端，用户可创建课程并上传主资料与补充资料。系统坚持“主资料优先”原则，主资料决定考查范围、题型风格、常考点、难度与答案标准，补充资料用于识别章节结构、理解课程背景和辅助生成解析。

系统基于 DeepSeek API 生成章节题库，并通过“生成 + Rubric 复核 + 不合格重写”的流程控制题目质量。每章按照 0-39、40-59、60-79、80-100 四个难度层生成题目，学生完成前置知识诊断后，系统自动匹配对应难度层开展练习。

项目创新点在于构建“题目嵌入式 AI 对话引导”机制。AI 并非脱离学习任务的开放聊天机器人，而是在学生选错、选择“模糊”或提交简答后，基于当前题目、学生答案、标准答案、知识点和评分点主动发起引导，并允许学生继续围绕该题对话，从而形成“有题可依、有错可诊、有问可追”的即时学习支架。
