# 趣味刷题小站

高校课程题库生成、审核、分层练习与受控 AI 辅导的本地网页应用。

## 本地启动

1. 安装 Node.js。
2. 在 `deepseek-config.js` 的 `apiKey` 中仅在本机填写自己的硅基流动 API Key；不要提交该文件中的真实 Key。
3. 双击 `启动趣味刷题小站.bat`。
4. 浏览器打开 `http://127.0.0.1:8766/趣味刷题小站第一版.html`。

## 发布版包含内容

- 当前运行页面和本地服务；
- 前两章题目预览；
- 项目说明与需求文档。

未包含本机 API Key、自动备份、学生学习记录和历史草稿。
